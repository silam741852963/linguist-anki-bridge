# CLI research and implementation plan

Revision: 2026-09-26. Status: implementation design selected by the assistant for user review; no implementation or collection migration performed.

Read alongside [the application specification](../application/README.md). This document provides researched technology choices, live collection evidence, the proposed new card standard, and the concrete delivery plan. The user's clarified scope supersedes the earlier vocabulary-first/grammar-deferred proposal: **revamp old vocabulary, revamp old grammar, add vocabulary, and add grammar are all release requirements**. Implementation details are delegated to the assistant to choose and present for review; they are no longer 34 separate questions blocking design work.

There is no universal industry schema for language-learning Anki cards. “New standard” below means a versioned application standard informed by Anki mechanics, recall-oriented design, preservation of the user's source material, and verified modern tooling. Versions and provider capabilities are dated observations, not promises that a moving `latest` will behave identically later.
