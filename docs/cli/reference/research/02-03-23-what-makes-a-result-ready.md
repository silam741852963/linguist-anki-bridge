# Research reference

### 2.3 What makes a result ready

Vocabulary: nonempty accepted expression and meaningful answer; a chosen exact/sense policy; valid source/target mapping; evidence or explicit author content; no unresolved blocking issue. Unknown headwords are allowed as author-created material if the user supplies a reviewed answer; a “not found” placeholder is not learning content.

Grammar: nonempty pattern, meaningful function, reviewed formation where needed, and at least one usable example or explicit authored equivalent. Do not accept “failed to parse explanation” as success. Recovered source patterns/negation/sentence text must survive normalization. Unsupported rule invention is flagged, not hidden by clean JSON.

Three examples is a generation target, not a compulsory review burden. Preserve all usable source examples in reference; select a short visible set on the back. Disagreement between source and generated grammar explanations is a blocking evidence review. Translation language defaults from configuration; Vietnamese legacy explanation is preserved in its source archive/PersonalNotes as appropriate even when new supporting translations are English.

All cards: stable semantic task, readable responsive layout, no front-side answer leakage, native sound tags, suitable text direction/script attributes, dark/light legibility, no dependency on a JavaScript framework or external CDN. Basic templates must work offline in supported Anki clients. Optional image licensing is tracked; commercial/legal suitability is not inferred from “found on Wikipedia.”
