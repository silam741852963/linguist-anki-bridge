# Application specification reference

### 3.1 Known discrepancies that the new specification must resolve

1. **Backup semantics:** README/manual language mentions required deck exports. Python config migration removes automatic pre-write backup configuration and its commit orchestration uses per-note snapshots. Rust's application commit calls `backup_deck`, but the live Anki adapter actually calls collection `createBackup`. Python's manual `.apkg` export uses `includeSched=False`. These are three different protections; **REVIEW R03**.
2. **Dictionary fidelity:** Python preserves entries, forms, senses, metadata, and related entries. Rust provider types can represent rich Jisho entries, but core `DictionaryData` and the desktop adapter reduce them to a definition string and pronunciation list. Fixture parity at the final HTML boundary does not establish live dictionary fidelity.
3. **OCR dependency:** Python passes raw OCR and dictionary evidence into vocabulary generation. The native desktop adapter calls enrichment before its existing-image OCR policy, so that later OCR cannot inform the already-generated examples.
4. **Classification:** Python returns a binary decision with `needs_confirmation` near the threshold; some surrounding code and docs instead discuss an `uncertain` state. Rust desktop uses OCR marker score and vision confidence. Do not interpret every Python `dictionary` label as safely confirmed.
5. **Provider routing:** Python's global default `jisho` can override other languages. Rust has language-sensitive routing helpers. Require per-purpose provider resolution.
6. **User context:** Python injection preserves author context for rendering, but vocabulary generation chiefly receives dictionary/OCR context. A not-found injection can skip generation. The Rust pipeline explicitly carries a context string. Context presence alone does not prove meaningful generated output.
7. **Grammar:** Python modernization can ask grammar generation using the expression rather than screenshot text in its primary path; other paths use raw OCR or crawled article text. Grammar source ownership needs an explicit target contract.
8. **Restore:** Python restores fields/media, but its ordinary same-model path does not fully establish restoration of deck/tag state. Native restore checks recorded post-write fields/model/deck/tags/media; legacy snapshots lack that guard. Neither should be described as full collection or scheduling restoration.
9. **Crash replay:** modernization field writes are repeatable, but injection and split-note creation require reconciliation when Anki accepts a write before the local receipt is saved. The existing job-state rewind alone is insufficient proof of exactly-once creation.
10. **Template coverage:** Rust defines managed English vocabulary and Japanese grammar as well as Japanese vocabulary. Python's installer is Japanese-specific. Generic Rust model selection defaults to Japanese for unrecognized purposes; the CLI must reject unsupported purpose/model combinations instead.
