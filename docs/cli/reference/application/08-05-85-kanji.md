# Application specification reference

### 8.5 Kanji

Run for Japanese expressions containing Kanji, not every language simply because its expression includes CJK characters. Deduplicate characters in stable order. English-oriented primary Jisho may fall back to KanjiAPI and HVDic; Vietnamese-oriented primary HVDic may fall back to Jisho and KanjiAPI per character. Preserve which source supplied each character and its actual language.

Keep meanings/readings, strokes, radical, parts, optional Sino-Vietnamese reading, and stroke-order image when available. Deterministic source data is preferable to an unmarked LLM summary; summarization must be explicitly labeled. Missing details for one character should not erase successful details for others. **REVIEW R20:** whether fallback content must be translated and whether stroke-order images become managed local assets rather than embedded data URIs.
