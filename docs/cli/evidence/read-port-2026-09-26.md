# Read-port smoke evidence — 2026-09-26

Scope: new CLI read-only transport and real API shapes. This is not native mutation, restore, crash-on-Anki or release-gate evidence. No collection mutation action, export, permission dialog, profile switch or service launch was called.

## Implemented port and fixture checks

The port has a private fixed read-action enum; there is no arbitrary-action public method. Pinned transport: reqwest 0.13.5, blocking JSON, Rustls, no redirects/system proxy/automatic retries. Response bytes and info batches use registry limits; credential names resolve only into request payloads. Primary transport reference: [reqwest 0.13.5](https://docs.rs/reqwest/0.13.5/reqwest/).

`crates/linguist-anki/tests/read_port.rs` uses temporary localhost HTTP fixtures for action names, numeric wire/string domain IDs, typed batch size, profile drift, native-advertisement versus verified readiness, error credential redaction, response bounds, strict envelopes/duplicate keys, info identity mismatch, redirect rejection and destination policy. Fixture tests do not connect to the user's Anki. The sandbox blocks socket listeners, so those tests require a runner permitting localhost networking.

## Live probe result

Commands completed successfully with AnkiConnect API v6:

```sh
cargo run --locked -- doctor
cargo run --locked -- decks list --counts --limit 10
cargo run --locked -- models list
cargo run --locked -- models inspect '2. Picture Words'
cargo run --locked -- models inspect 'Cơ bản'
cargo run --locked -- notes count --query ''
cargo run --locked -- notes list --query '' --limit 2
```

Doctor reported the expected read actions and no `labCapabilities` advertisement. Readiness was read-only; native verification and collection writes were false. IDs appeared as decimal strings. The note list omitted field values and returned an ID-set-bound cursor. Private note fields, profile/deck names and collection identifiers are not copied into this report.

`2. Picture Words` field order observed: Word; Picture; Gender, Personal Connection, Extra Info (Back side); Pronunciation (Recording and/or IPA); Test Spelling? (y = yes, blank = no). Template names observed: Comprehension Card, Production Card, Spelling?. Their order remains unverified because `modelTemplates` supplies a name-keyed map without ordinals.

`Cơ bản` fields observed: Mặt trước, Mặt sau; template name Thẻ 1. This reinforces exact localized source mapping, not hardcoded English Basic-field assumptions. The shared recording/IPA field must be archived in full before separating audio from pronunciation text.

Deck-count output labels subdeck inclusion. This follows [Anki search semantics](https://docs.ankiweb.net/searching.html#tags-decks-cards-and-notes); deck quoting also escapes literal wildcard characters. Note/card counts come from separate reads and do not certify an atomic collection snapshot.
