## Progress audit — 2026-10-04 (partial; WP-15 is not complete)

Delivered:
- Release build: `scripts/release-build.py` runs `cargo build --locked --release -p linguist-cli` with the HEAD commit time as SOURCE_DATE_EPOCH and remapped paths. It refuses a dirty tree and any Qt/QML crate in the CLI dependency closure or `NEEDED` libraries. It writes a deterministic tar.gz, `build-manifest.json` and `SHA256SUMS` under `dist/release/` and never installs. `--verify-reproducible` builds twice and compares. A `[profile.release]` was added (codegen-units 1, strip symbols). The script was written but not yet run end to end.
- MSRV: the workspace test suite passed on Rust 1.98.1 (553 tests, before this package's changes) using a toolchain installed by `mise` into `~/.rustup`.
- UX: every command and argument has help text (guarded by `release_ux.rs`). Syntax errors report `usage_kind` and, for defined arguments, the argument name, still without echoing values. Errors for optional dependencies, unavailable capabilities and limits carry a `next` step (`crates/linguist-cli/src/remedy.rs`). SIGINT exits 130 and SIGTERM 143 with a structured `INTERRUPTED` error. The editor ignores SIGINT while it runs. Commands that write state check `storage.free_space_reserve_mb` plus an estimate first (`STORAGE_FREE_SPACE`).
- Bug fix found by the fresh-home tests: default dictionary lookups always failed with `CAPABILITY_UNAVAILABLE: PROVIDER_READ_Policy` because `${XDG_CACHE_HOME}` was expanded with an empty environment. `dictionary::enrich_document` now receives the environment.
- Tests: `crates/linguist-cli/tests/release_ux.rs` covers fresh home, help, offline authored prepare→validate→approve→apply preview→export, SSH/dumb terminal, JSONL, Unicode paths, non-UTF-8 arguments, piped stdin, a closed stdout pipe, SIGINT/SIGTERM, dependency guidance, batch and file limits and the free-space reserve. `release_coverage.rs` adds OP-07, OP-15, OP-16 and OP-20. `crates/linguist-config/tests/presets.rs` pins the final purpose presets. `crates/linguist-application/tests/semantic_corpus.rs` runs the EV-11 deterministic corpus: 120 annotated fixtures (`scripts/generate-semantic-corpus.py`), 30 per workflow and 15 Japanese plus 15 English each, all passing with the corpus policy checks.
