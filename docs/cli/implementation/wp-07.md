## Completion audit — 2026-10-03

- Add and revamp: both run ALG-CAPTURE, OCR (revamp images under `images.existing_policy=inspect`), dictionary lookup and then optional enrichment. Each produces immutable v2 plan revisions. Revamp keeps every intermediate revision. Neither command writes to Anki.
- Reviewed choices: the expression (from one OCR region when missing), sense (existing typed decisions), picture/audio candidates (`media`) and collection duplicates (`duplicate` after `--record`) are typed, persisted decisions. Each is offered as a decision template.
- Preservation: authored context, notes, prompts and examples stay unchanged. Revamp source cards, tasks, task maps and source media are retained; enrichment fills only empty fields and never replaces source media.
- Enrichment after OCR/dictionary: Jisho kanji, Wikimedia picture candidates and Piper audio candidates are staged with provenance, rights and inspection evidence. Optional failures are warnings.
- Task cues: Production/Spelling cue templates carry leak-checked suggestions, including the kana reading for Japanese kanji words, and validation still blocks leaks. With `llm.enabled=true`, generation runs for eligible items and fills only empty fields.
- Ready/review: receipts report readiness, issues and exact next commands; ready plans remain unapproved and unapplied.
