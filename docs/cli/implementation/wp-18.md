## WP-18 — review paths for rich Picture Words sources

Touch: `crates/linguist-application/src/{capture,revamp}.rs`, `crates/linguist-core/src/{review,validation,editing,records}.rs`. Found while revamping the user's real `2. Picture Words` notes (俳優) after WP-17.

Steps:

1. Colour-only inline styles are not media syntax.
2. `[sound:]` markers in a text field are stripped to a reviewable derived value.
3. Picture/audio fields holding only captured media need no extra role review.
4. The native task map resolves enable-field task candidates and adds the mapped tasks.
5. A typed `missing_media` decision acknowledges files absent from the collection.
6. `plans edit` may fill an empty Meaning or SenseKey.
7. The missing-media review reopens when a later decision clears its decision.
